# Manolya Hobievi – Veritabanı Entegreli Web Uygulaması

## Proje Hakkında

Manolya Hobievi, PHP ve MySQL kullanılarak geliştirilmiş veritabanı entegreli bir e-ticaret web uygulamasıdır. Projede ürün, kategori, müşteri ve sipariş bilgilerinin ilişkisel veritabanında yönetilmesi ve web arayüzü üzerinden görüntülenmesi amaçlanmıştır.

## Kullanılan Teknolojiler

- **PHP:** Sunucu taraflı programlama
- **MySQL:** İlişkisel veritabanı yönetimi
- **MySQLi:** Veritabanı bağlantısı ve sorgu işlemleri
- **HTML5 & CSS3:** Web arayüzü geliştirme
- **JavaScript:** Kullanıcı etkileşimleri

## Temel Özellikler

- PHP ve MySQL ile veritabanı bağlantısı.
- Ürün ve kategori bilgilerinin veritabanında yönetilmesi.
- Müşteri ve sipariş tablolarının oluşturulması.
- SQL sorguları ile veri ekleme, silme, güncelleme ve listeleme.
- Veritabanı işlemlerinin gerçekleştirilebildiği SQL sorgu arayüzü.

## Veritabanı Yapısı

Projede aşağıdaki temel tablolar kullanılmıştır:

- `kategori`
- `urun`
- `musteri`
- `siparis`
- `siparis_detay`

## Kazanılan Teknik Yetkinlikler

PHP ile backend geliştirme, MySQL veritabanı tasarımı, SQL sorguları, veritabanı bağlantısı ve dinamik web uygulaması geliştirme konularında uygulamalı deneyim kazanılmıştır.
